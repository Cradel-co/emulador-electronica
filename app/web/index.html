      Acerca de
      
        
      Emulador de electrónica: prototipado de placas programables (ESPHome, ESP-IDF C/C++, Arduino, MicroPython)
          con emuladores reales. Ver docs/vision-y-alcance.md para el alcance y lo que falta.

      Nuevo proyecto
      
        
        
        
      
        
        
        
      Solo [a-z0-9-], hasta 40 caracteres. Las plantillas viven en projects/_template/.
      
        
          
          
        
      
      
          

    
      
      
        
      Agregar placa
      
        
      El proyecto no tiene placa. Al agregarla vas a poder programarla; el circuito queda como está.
      
        
        
        
          
          
        
      
      
          

    
      
      
        
      Importar módulos
      
        
      
          
          
          
          
        
      
        
      
          
      Una carpeta con module.json + module.svg, o una con varias subcarpetas (una por módulo). También toma los .chip.json de Wokwi que encuentre.
      
          
        
      
        
      
          
      Un .zip con uno o varios módulos (y/o chips de Wokwi).
      
          
        
      
        
      
          
      El .chip.json de un chip custom de Wokwi. Se importan sus pines con un dibujo genérico; la lógica del chip (WASM) no se ejecuta.
      
          
          
          
        
      
        
      
          
      Un link https:// a un .zip, un module.json, un .chip.json, o un repo de GitHub (https://github.com/dueño/repo o …/tree/rama/carpeta).
