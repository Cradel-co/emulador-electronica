# Resistencias en paralelo

A 5 V, las ramas de 1 kΩ y 2 kΩ toman 5 mA y 2,5 mA. La fuente aporta 7,5 mA.

La fuente empieza apagada. Abrí una copia desde Aprender y presioná ▶ para energizar el circuito. Abrí Debug → Alimentación y consumo y desplegá Componentes para observar tensiones, corrientes y potencia. Los valores indicados son para régimen DC y componentes ideales, antes de modificar el ejemplo.
