# Una rama abierta

R2 conserva su resistencia de 2 kΩ pero su terminal 1 queda desconectado. Solo R1 de 1 kΩ conduce: 5 mA.

Variante educativa del ejemplo `paralelo`. La fuente comienza apagada. Presioná ▶ y consultá Debug → Alimentación y consumo → Componentes. Las predicciones son ideales; usá la salida medida de la fuente para el balance.
