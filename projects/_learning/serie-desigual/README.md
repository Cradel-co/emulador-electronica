# Resistencias distintas en serie

Con 5 V, R1 = 1 kΩ y R2 = 2 kΩ, la corriente es 1,667 mA. Las caídas son 1,667 V y 3,333 V.

Variante educativa del ejemplo `serie`. La fuente comienza apagada. Presioná ▶ y consultá Debug → Alimentación y consumo → Componentes. Las predicciones son ideales; usá la salida medida de la fuente para el balance.
