# Práctica: encender un LED

Un circuito sin placa para explorar una fuente de 5 V, una resistencia de 330 Ω y un LED rojo. La fuente empieza apagada.

## Experimentos

1. Encendé la fuente y observá el LED y la corriente que calcula el simulador.
2. Apagá la fuente, invertí el LED y volvé a encenderla para comparar.
3. Apagá la fuente y restaurá la orientación inicial.

La resistencia queda en serie durante todos los pasos; no la quites.
